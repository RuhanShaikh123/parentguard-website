Installer Wizard

A focused setup assistant that helps an authorized parent install and configure ChildGuard, the supervised-device companion, on a compatible Android device.

Get the official Wizard → Installation help
Setup steps

How to use the Installer Wizard.

1

Start from the family setup

Use ParentGuard's pairing/setup flow and follow the displayed instructions.

2

Download the official package

Use only the official Wizard URL published by ParentGuard. Do not use unofficial mirrors.

3

Android authorization

Android may require permission to install apps from the source used for the download.

4

Finish supervised setup

Open ChildGuard and complete the pairing and permission setup on the supervised device.

Security note: Never install an APK obtained from an unofficial mirror or a modified copy. Use only the official ParentGuard download URL and verify the package source.

Why a separate Wizard exists

The Wizard is an installation helper, not a replacement for ParentGuard and not the component that provides family monitoring services. Keeping these responsibilities separate makes the product architecture easier to explain and support.

APK distribution

The production website is configured so you can change the Wizard URL in assets/js/config.js without rewriting the site. Connect the button to your real signed release only.
