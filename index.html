Capabilities

Built around the tools your family actually needs.

Feature availability depends on Android version, device restrictions, granted permissions and the configuration selected by the parent.

⌖

Live location

When location sharing is enabled and the required Android permissions are granted, ChildGuard can send location updates to the paired family account.

◉

Live audio

The supervised device can provide live microphone audio when the feature is enabled and microphone permission is granted.

▣

Live camera

The camera service supports live camera functionality when enabled and the camera permission is granted.

▤

Live screen

Screen sharing uses Android MediaProjection and requires the system's screen-capture authorization.

◫

Device activity controls

Android Usage Access and Accessibility capabilities may support device-management functions where enabled and disclosed.

✓

Permission transparency

Sensitive capabilities are documented so parents can understand what each permission enables before using the related feature.

FAQ

Questions parents should ask before setup.

Is ChildGuard intended for secret surveillance?

No. ChildGuard is designed as a parent/guardian-managed family safety system. It should not be used to secretly monitor spouses, partners, employees, friends, or other adults without lawful authority and appropriate consent.

Why does the supervised device need sensitive permissions?

Features such as location, microphone, camera, screen sharing, Accessibility and Usage Access require Android capabilities. Each is documented on our Data & Permissions page and should be enabled only when the corresponding family-safety feature is needed.

Does ChildGuard record everything?

The website does not promise unlimited recording. Real-time features are feature-specific and depend on the app configuration, Android permission state and connection. See the Data & Permissions page for the current documented behavior.

Can I delete my account?

Yes. See our Account Deletion page for the current deletion request process. The production backend must be configured to actually execute deletion requests.

Will every feature work on every Android phone?

No. Android version, OEM restrictions, battery optimization, permission state and system policies can affect behavior. The setup flow should tell users when a device-specific limitation applies.
