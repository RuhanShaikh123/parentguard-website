Core features

What ParentGuard provides.

⌁

Family pairing

Connect a supervised Android device to the parent family account using the supported pairing flow.

⌖

Location

View location information sent by the paired device when location sharing is enabled.

◉

Live safety tools

Where supported, initiate live audio, camera or screen features from the parent experience.

📶

Device status

See the real-time connection and permission status of the supervised device from the parent dashboard.

✅

Permission visibility

Understand which permissions are active on the supervised device and which features are enabled.

🔐

Secure connection

The parent and supervised device communicate over a secured, authenticated family data path.

Parent responsibilities

  • Use the service only for devices and people you are legally authorized to supervise.
  • Explain the purpose of the supervised-device app and its permissions in an age-appropriate way.
  • Do not use the service to secretly monitor adults or evade Android security controls.
  • Keep account credentials secure and remove paired devices that are no longer under your supervision.
