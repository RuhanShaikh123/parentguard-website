# ChildGuard Play Store pre-launch checklist

This website supports the public documentation layer. It does not by itself make the APK compliant.

Before submission:
- [ ] Privacy policy URL is live over HTTPS and matches the production APK/backend.
- [ ] Privacy policy is accessible inside the ParentGuard app.
- [ ] Data Safety form matches actual SDKs, data collection and sharing.
- [ ] Account deletion is implemented in-app if accounts can be created.
- [ ] External account deletion URL is live and functional.
- [ ] Accessibility API declaration is completed if applicable.
- [ ] Accessibility use is disclosed clearly and matches the actual core functionality.
- [ ] Background location declaration is completed if applicable.
- [ ] Background location is genuinely core to the disclosed feature set.
- [ ] Sensitive permissions are requested only when needed.
- [ ] In-app prominent disclosure/consent is implemented where required.
- [ ] Foreground-service notifications accurately describe ongoing sensitive services.
- [ ] Play listing accurately describes the ParentGuard app and its relationship to the supervised app.
- [ ] The Wizard is not represented as a secret or deceptive installer.
- [ ] Public website wording matches the real feature set; do not claim features not shipped.
- [ ] Production release is signed, versioned and distributed from an authoritative source.
- [ ] Support email and legal/contact details are correct.
- [ ] Remove all placeholders from config.js, sitemap.xml and legal pages.
